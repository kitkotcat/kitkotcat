# QA Cat Recorder — Support

Для вопросов, сообщений о проблемах и feature requests по QA Cat Recorder используйте контакты ниже.

## Что приложить к сообщению о проблеме

- версия Chrome и операционной системы;
- краткие Steps to Reproduce;
- Expected Result;
- Actual Result;
- screenshot при необходимости.

Пожалуйста, не публикуйте пароли, токены, OTP, API keys и другие чувствительные данные.
